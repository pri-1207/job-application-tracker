Features

Everything you need to manage your job search

📝

Full CRUD Operations

Create, read, update, and delete job applications, companies, and interview records via clean REST endpoints.

🔍

Dynamic Filtering & Sorting

Filter applications by status, company, role title, and date range. Sort by any field in ascending or descending order.

✅

Request Validation

Bean Validation with detailed field-level error messages. All inputs are validated before processing.

🛡️

Centralized Exception Handling

Global exception handler returns consistent API error responses with status codes, messages, and timestamps.

📊

Pagination Support

All list endpoints support pagination with configurable page size, page number, sort field, and direction.

📄

Interactive API Docs

Auto-generated Swagger UI at /swagger-ui.html for exploring and testing all endpoints interactively.

API Reference

All endpoints are prefixed with /api/v1

🏢 Companies

GET /api/v1/companies List all companies (sortable)
GET /api/v1/companies/{id} Get company by ID
GET /api/v1/companies/search?name= Search companies by name
POST /api/v1/companies Create a company
PUT /api/v1/companies/{id} Update a company
DELETE /api/v1/companies/{id} Delete a company

📋 Job Applications

GET /api/v1/applications List all (paginated, sortable)
GET /api/v1/applications/{id} Get application by ID
GET /api/v1/applications/filter?status=&companyId=&roleTitle=&startDate=&endDate= Dynamic filter
GET /api/v1/applications/status/{status} Get by status
POST /api/v1/applications Create an application
PUT /api/v1/applications/{id} Update an application
PATCH /api/v1/applications/{id}/status Update status only
DELETE /api/v1/applications/{id} Delete an application

🎤 Interviews

GET /api/v1/interviews List all interviews
GET /api/v1/interviews/{id} Get interview by ID
GET /api/v1/interviews/application/{applicationId} Get by application
GET /api/v1/interviews/upcoming Get upcoming interviews
POST /api/v1/interviews Schedule an interview
PUT /api/v1/interviews/{id} Update an interview
DELETE /api/v1/interviews/{id} Delete an interview

Example Requests

Create a Company

POST /api/v1/companies
Content-Type: application/json

{
  "name": "Google",
  "industry": "Technology",
  "website": "https://google.com",
  "location": "Mountain View, CA"
}

Create a Job Application

POST /api/v1/applications
Content-Type: application/json

{
  "roleTitle": "Software Engineer",
  "description": "Full-stack development role",
  "applicationDate": "2026-10-14",
  "companyId": 1,
  "salaryRange": "$120k - $160k",
  "workType": "Remote"
}

Filter Applications

GET /api/v1/applications/filter?status=INTERVIEWING&sortBy=applicationDate&sortDir=desc&page=0&size=10

Quick Start

Get up and running in minutes

1

Prerequisites

Ensure you have Java 17+, PostgreSQL 14+, and Git installed.

2

Clone the Repository

git clone https://github.com/YOUR_USERNAME/job-application-tracker.git
cd job-application-tracker
3

Create the Database

psql -U postgres
CREATE DATABASE job_tracker_db;
4

Configure & Run

# Update database credentials in application.properties if needed
./mvnw spring-boot:run

The API will be available at http://localhost:8080

Swagger UI at http://localhost:8080/swagger-ui.html
